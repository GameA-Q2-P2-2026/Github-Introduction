# 📚 GitHub Introduction & Class List

Welcome to CSC1001! This repository is designed to help you get comfortable working with Git and GitHub Desktop. 

For your first assignment, you will clone this repository, create your own branch, add your first name to the class list, and review a classmate's pull request. Follow the step-by-step instructions below.

## Step 1: Clone the Repository
1. Open **GitHub Desktop**.
2. Go to the top menu and select **File** > **Clone repository...**
3. Click on the **URL** tab.
4. Paste the following URL into the repository box:
   `https://github.com/Mazzia-CSC1001/Github-Introduction.git`
5. Choose a "Local Path" on your computer where you want to save the project folder (e.g., your Documents folder).
6. Click the blue **Clone** button.

## Step 2: Create a Branch
Branches let you safely make changes on your own version without affecting the main project.
1. In GitHub Desktop, verify your "Current repository" in the top left says `Github-Introduction`.
2. Click on **Current branch** at the top of the window.
3. Click the **New branch** button.
4. Name your branch using your first name (e.g., `jane-doe`) and click **Create branch**.
5. Click the blue **Publish branch** button to send your new branch to GitHub.

## Step 3: Add Your Name
1. In GitHub Desktop, click **Show in Explorer** under the repository tab to open the repository folder on your computer.
2. Open the class list file in your preferred text editor (Notepad, TextEdit, VS Code, etc.).
3. Type your first name at the bottom of the list.
4. Save the file and close your text editor. (Ctrl+S is the shortcut to save)

## Step 4: Commit and Push Your Changes
1. Go back to GitHub Desktop. You will see your changed file listed on the left side of the screen.
2. In the bottom-left corner, find the commit summary box. Type a short, descriptive message like: *"Added [Your Name] to the class list"*.
3. Click the blue **Commit to [your-branch-name]** button.
4. Click the **Push origin** button at the top of the screen to upload your saved changes to GitHub.

## Step 5: Open a Pull Request
1. After pushing, a new button will appear in GitHub Desktop that says **Create Pull Request** in blue (under where it should say "No local changes"). Click it.
2. Your web browser will open directly to the GitHub website.
3. Review the page to make sure your changes look correct. 
4. Add a title to your Pull Request (e.g., "Add [Your Name] to class list") and click the green **Create pull request** button.

## Step 6: Assign a Classmate
1. On the right side of your newly created Pull Request page, look for the **Reviewers** section.
2. Click the gear icon ⚙️ next to it.
3. Search for a classmate's GitHub username and select them so they are notified to review your work.

## Step 7: Review a Classmate's Work
1. Go to the main page of this repository on GitHub and click the **Pull requests** tab at the top.
2. Find the Pull Request that your classmate assigned to you and click on it.
3. Click the **Files changed** tab near the top to see exactly what they added.
4. If everything looks correct (they only added their name to the list), click the green **Review changes** button in the top right.
5. Select **Approve**, leave a friendly comment (like "Looks great!"), and click **Submit review**.
6. Finally, go back to the "Conversation" tab and click the green **Merge pull request** button to officially add their name to the main class list!
